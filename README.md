# ⚖️ 디스코드 내전 팀 나누기 봇

대기방 음성 채널에 모인 사람들을 **두 팀으로 나눠**, 미리 만들어 둔 두 개의 음성 채널로 한 번에 옮겨 주는 봇이에요. 팀은 점수(티어)를 고려해 **최대한 균형 있게** 나눌 수 있고, 경기 결과를 버튼 한 번으로 정산해 점수·승패를 기록합니다.

- `/팀나누기` — 지금 들어 있는 음성 채널(대기방) 인원을 두 팀으로 나눠 이동
  - `방식`: **밸런스**(기본, 팀 평균 점수차 최소) / **무작위**
- 결과 메시지 버튼 — **🔀 다시 섞기**, **🏆 1팀 승리**, **🏆 2팀 승리**, **📢 대기방으로 모으기**
- `/모이기` — 두 팀 채널에 흩어진 인원을 한 채널로 다시 모으기
- `/점수설정` — 멤버 점수 직접 설정 (0~5000)
- `/점수초기화` — 멤버 하나 또는 서버 전체를 1000점·0승 0패로
- `/랭킹` — 티어·점수·승패·승률 순위표
- `/기록채널` — 점수 JSON 백업용 텍스트 채널 지정 (재시작해도 점수 복구)

---

## 1. 준비물

| 준비 | 설명 |
| --- | --- |
| 디스코드 봇 | 디스코드 개발자 포털에서 무료로 만들 수 있어요 |
| 음성 채널 3개 | `대기방`(사람들이 모이는 곳), `팀 1`, `팀 2` |
| 텍스트 채널 1개 (선택) | 점수 백업용. `/기록채널` 로 지정하거나 이름을 `소현봇-기록` 으로 |
| 파이썬 3.10 이상 | 로컬에서 돌릴 때만 필요 (호스팅에 올리면 자동) |

## 2. 봇 만들기 (한 번만)

1. <https://discord.com/developers/applications> → **New Application** → 이름 입력(예: 팀나누기)
2. 왼쪽 **Bot** → **Reset Token** → 토큰 복사 (이 값은 절대 공개하지 마세요)
3. 같은 화면 아래 **Privileged Gateway Intents** → **SERVER MEMBERS INTENT** 를 **ON**
   (이게 꺼져 있으면 봇이 켜지지 않아요. `MESSAGE CONTENT INTENT` 는 필요 없어요)
4. 왼쪽 **OAuth2 → URL Generator**
   - Scopes: `bot`, `applications.commands`
   - Bot Permissions: `View Channels`, `Move Members`
     (+ 점수 기록 채널을 쓰려면 `Send Messages`, `Read Message History`, `Manage Messages`)
   - 만들어진 링크로 봇을 서버에 초대

> 빠른 초대 링크 (위 권한 그대로):
> `https://discord.com/api/oauth2/authorize?client_id=봇_애플리케이션_ID&permissions=16778240&scope=bot%20applications.commands`

## 3. 설치하고 실행하기 (내 컴퓨터에서)

```bash
cd discord_team_bot
pip install -r requirements.txt
cp .env.example .env          # Windows: copy .env.example .env
```

`.env` 를 열어 토큰을 넣어 주세요.

```env
DISCORD_BOT_TOKEN=여기에_복사한_토큰
```

실행:

```bash
python bot.py
```

`로그인 완료: ...` 가 뜨면 성공이에요. 슬래시 명령어는 봇이 접속한 **모든 서버에 길드 명령어로
곧바로 등록**되므로 새 명령어도 디스코드에 바로 보입니다(전역 목록은 중복 방지를 위해 비웁니다).
그래도 안 보이면 디스코드 앱을 껐다 켜 주세요(입력창에 `/` 를 치면 목록이 새로 고쳐집니다).

## 4. 사용법

### 팀 나누기

1. **대기방** 음성 채널에 사람들이 모입니다.
2. 아무 음성 채널에서 `/팀나누기` 를 입력하고 `팀1_채널`, `팀2_채널` 을 고릅니다.
   `방식` 은 비워 두면 **밸런스**(점수 기준)이고, `무작위` 도 고를 수 있어요.
3. 팀이 공개되고 모두 각 팀 채널로 이동합니다.
4. 결과 메시지의 버튼
   - **🔀 다시 섞기** — 같은 인원을 같은 방식으로 다시 섞어 이동 (새 판으로 리셋, 버튼은 30분 동안 사용 가능)
   - **🏆 1팀 승리 / 🏆 2팀 승리** — 이긴 팀 기준으로 점수를 정산하고 결과 임베드에 변동 점수를 표시
     (한 판에 한 번만 정산돼요. 다시 누르면 무시됩니다.)
   - **📢 대기방으로 모으기** — 두 팀 채널 인원을 처음 대기방으로 복귀
5. 팀 채널에 흩어진 인원을 한 번에 모으려면 `/모이기` → `대상_채널1`(, `대상_채널2`),
   `모일_채널` 은 비워 두면 지금 계신 채널로 모여요.

> 버튼은 명령을 실행한 사람과 **'멤버 이동'** 권한이 있는 사람만 누를 수 있어요.

### 점수 · 티어

- 새 멤버는 **1000점(0승 0패)** 에서 시작합니다.
- 승리 시 **+15 ~ +35점**, 패배 시 **-15 ~ -30점** (양 팀 평균 점수 차이에 따라, 동점이면 승 +25 / 패 -20).
  점수가 낮은 팀이 이기면 더 많이 오르고, 진 팀은 적게 잃어요. 점수는 0점 아래로 내려가지 않습니다.
- 티어: 👑 챌린저 1500+ · 💎 다이아 1350~1499 · 💠 에메랄드 1200~1349 · 🔷 플래티넘 1100~1199 ·
  🥇 골드 1000~1099 · 🥈 실버 900~999 · 🥉 브론즈 800~899 · 🪨 아이언 ~799
- `/점수설정 멤버 1400` 처럼 미리 실력을 맞춰 둘 수 있어요. (0~5000)
- `/점수초기화` 는 멤버를 비우면 서버 전체를 초기화합니다.
- `/랭킹` 으로 순위표를 확인할 수 있어요.

### 점수 저장 · 백업

- 점수는 `data/scores.json` 에 저장되고, `/기록채널` 로 정한 텍스트 채널에 **JSON 백업 메시지**를
  남깁니다(자동 고정). `/기록채널` 을 따로 정하지 않아도, 서버에 이름이 **`소현봇-기록`** 인
  텍스트 채널이 있으면 자동으로 그 채널을 씁니다.
- 봇이 새로 켜졌을 때 메모리에 점수가 없으면 그 채널의 백업 메시지에서 **자동 복구**합니다.
  (Render 무료 플랜처럼 배포 때마다 파일이 사라지는 환경에서 특히 필요해요.)
- 채널 읽기/쓰기 권한이 없어도 봇은 죽지 않고 파일에만 저장하며 정상 동작합니다.
  백업까지 쓰려면 봇 역할에 **메시지 보내기 / 채널 기록 읽기 / 메시지 관리(고정)** 권한을 주세요.

## 5. 무료 클라우드에서 24시간 돌리기

Render · Koyeb · Cloudtype 처럼 **Web Service(웹 서비스)** 타입으로 올리면 되고,
설정은 세 가지예요.

| 항목 | 값 |
| --- | --- |
| Build / Install Command | `pip install -r requirements.txt` |
| Start Command | `python bot.py` |
| 환경변수 | `DISCORD_BOT_TOKEN` (필수) |
| 선택 환경변수 | `DISCORD_GUILD_ID` (특정 서버를 로그인 전에 미리 등록), `SCORE_FILE` (점수 파일 경로, 기본 `data/scores.json`) |
| Health Check Path | `/health` |
| 배포 방식 | GitHub 저장소 연결 후 Python 또는 Dockerfile 빌드 |

- 호스팅이 포트를 자동으로 넣어 주는 경우(`PORT` 환경변수) 봇이 **같은 프로세스 안에서
  가벼운 헬스체크 서버를 백그라운드 스레드로** 함께 띄웁니다. 그래서 "포트를 열지 않았다"며
  컨테이너를 죽이는 문제가 생기지 않아요. 추가 패키지나 별도 파일은 없습니다.
- `PORT` 가 자동으로 들어오지 않는 호스팅이라면 환경변수에 `ENABLE_HEALTH_SERVER=true`
  를 추가하세요 (8080 포트로 열립니다). 브라우저로 `http://내주소/health` 를 열어
  `{"status": "ok"}` 가 보이면 정상이에요.
- Worker(백그라운드 작업) 타입은 포트가 필요 없어서 `PORT` 없이 그냥 `python bot.py` 만
  넣으면 됩니다.
- 무료 플랜 중에는 일정 시간 요청이 없으면 잠드는 호스팅도 있어요. 24시간 깨어 있게 하려면
  그 호스팅의 슬립 설정을 확인하거나, 외부 핑 서비스로 `/health` 를 주기적으로 호출해 주세요.
- **GitHub 에 올릴 때 `.env` 는 절대 올리지 마세요.** (같은 폴더의 `.gitignore` 가 막아 줍니다.
  호스팅에는 토큰을 환경변수로 넣습니다.)

로컬에서 헬스체크까지 확인하려면:

```bash
# macOS / Linux
PORT=8080 python bot.py &
curl http://localhost:8080/health
```

### Docker 로 올리는 호스팅 (Koyeb·Cloudtype·Fly.io 등)

같은 폴더의 `Dockerfile` 을 그대로 쓰면 됩니다. 저장소를 GitHub 에 올리고
호스팅에서 "Dockerfile" 빌드를 고른 뒤 환경변수만 넣어 주세요.

```bash
# 로컬에서 미리 확인
docker build -t team-bot .
docker run --rm -e DISCORD_BOT_TOKEN=토큰 -e PORT=8080 -p 8080:8080 team-bot
curl http://localhost:8080/health
```

## 6. 안 되면

| 증상 | 해결 |
| --- | --- |
| 봇이 켜지지 않고 `PrivilegedIntentsRequired` | 개발자 포털 → Bot → **SERVER MEMBERS INTENT** ON |
| `LoginFailure` / 토큰 오류 | 토큰을 다시 복사 (Reset Token 후 새 값) |
| 명령어가 안 보여요 | 봇이 접속한 서버에 길드 명령어로 즉시 등록됩니다(전역은 비움). 디스코드 앱을 껐다 켜거나 입력창에 `/` 를 쳐서 목록을 새로 고쳐 보세요. 그래도 안 되면 Render 로그에 `길드 명령어 동기화 완료` 가 있는지 확인 |
| "먼저 대기방 음성 채널에 들어간 뒤..." | 봇을 부른 사람이 음성 채널에 있어야 해요 |
| "인원이 1명뿐이에요" | 봇 제외 2명 이상 필요 |
| "멤버 이동 권한이 없어요" | 봇 역할에 **Move Members** 권한, 해당 채널 권한에서도 허용 |
| 점수 백업이 안 보여요 | 봇 역할에 **Send Messages / Read Message History / Manage Messages** 권한, `/기록채널` 로 채널 지정 |
| 봇을 재시작했더니 점수가 초기화됐어요 | 기록 채널(또는 `소현봇-기록`)에 백업 메시지가 있는지 확인 (권한이 없으면 파일에만 저장됨) |
| 일부만 이동했어요 | 서버 설정 → 역할에서 봇 역할을 팀 채널들보다 위로 올리거나 채널 권한 확인 |
| `헬스체크 서버를 열지 못했어요` | 다른 프로그램이 그 포트를 쓰는 중. `PORT` 값을 바꾸거나 헬스체크를 끄세요 (봇은 계속 동작) |

## 파일 구성

```
discord_team_bot/
├── bot.py            # 봇 전체 코드 (명령어·버튼·점수·백업·헬스체크 서버)
├── tests/test_bot.py # 점수·티어·밸런스·저장/복구 단위 테스트
├── requirements.txt  # discord.py, python-dotenv
├── .env.example      # 환경변수 예시 (복사해서 .env 로)
├── Dockerfile        # 무료 클라우드(Docker) 배포용
├── .gitignore        # .env, data/, __pycache__ 등 제외
└── README.md         # 이 문서
```

테스트 실행:

```bash
python3 -m unittest discover -s tests -v
```
